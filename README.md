# RafayShhh Portfolio

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Frafayshhh%2Fportfolio-website)

This repository contains the source code for the RafayShhh portfolio website (`rafayshhh.site`).

## 🚀 Overview

A high-performance portfolio showcasing Minecraft modifications, native Android applications, and full-stack software projects. Designed with a focus on clean, lightweight, and bloat-free engineering.

## 🛠 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Deployment**: [Vercel](https://vercel.com/)
- **Analytics**: [Vercel Analytics](https://vercel.com/analytics) & [Speed Insights](https://vercel.com/speed-insights)

## 📦 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rafayshhh/portfolio-website.git
   cd portfolio-website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

## 🔒 Security & Confidentiality

- **Secrets**: This project uses environment variables. **NEVER** commit your actual `.env` files to the repository. Use the provided `.env.example` as a template for required configuration.
- **Environment Variables**: Sensitive API keys and configuration must be managed through Vercel's [Environment Variables dashboard](https://vercel.com/docs/projects/environment-variables).
